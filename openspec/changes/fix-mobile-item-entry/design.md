## Context

目前 `autoUpdate`、`skipWaiting` 與 `controllerchange` 無條件重整會中斷編輯；表單初始化 effect 依賴 stocks 陣列，背景資料刷新也會把輸入清空。

## Decisions

- 每次開啟建立單一表單工作階段，後續 props 刷新不重設。關閉後再開啟才重新初始化。
- 表單只透過明確關閉／取消／儲存操作離開；忽略背景點擊及 IME 組字中的 Escape。
- 使用原生 Service Worker 註冊，關閉自動注入與立即啟用。更新就緒僅通知，點擊更新才傳送 `SKIP_WAITING`，啟用後重整一次。其他分頁啟用新版不觸發本頁重整。
- 更新提示及自動版本說明延後到所有編輯視窗關閉。
- 洗髮精共用範本使用 cycle 而非虛構保存期限，預設 60 天可調整，門檻 1 件。

## Risks

舊版已載入的 JavaScript 仍保有原本自動重整處理，必須首次重新開啟以載入修正。桌面瀏覽器模擬無法涵蓋實體 iOS 鍵盤行為。

## Validation

測試背景更新、跨分頁啟用、使用者主動套用、離線註冊失敗與範本一致性；瀏覽器驗證手機 viewport 縮小、中文輸入、背景點擊、props 更新與儲存，並執行建置及 UTC／非台灣時區測試。
